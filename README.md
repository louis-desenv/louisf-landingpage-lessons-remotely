# Estrutura do Site

Este projeto organiza uma landing page principal e páginas específicas de aulas de guitarra, com estilos e recursos compartilhados.

## Visão geral

```text
louisf-landingpage-lessons-remotely/
|-- index.html
|-- contato.html
|-- robots.txt
|-- sitemap.xml
|-- css/
|   `-- style.css
|-- images/
|-- brazilian-guitar/
|   `-- index.html
|-- jazz-guitar/
|   `-- index.html
|-- play-like-slash/
|   `-- index.html
`-- rock-improvisation/
    `-- index.html
```

## Explicação por arquivo/pasta

- `index.html`: página inicial do site (landing page principal).
- `contato.html`: página de contato.
- `robots.txt`: instruções para rastreadores de busca (SEO técnico).
- `sitemap.xml`: mapa do site para facilitar indexação nos buscadores.

- `css/style.css`: folha de estilo global usada para padronizar o visual.
- `images/`: diretório de imagens usadas nas páginas (banners, ícones, fotos etc.).

- `brazilian-guitar/index.html`: página dedicada à aula/tema de guitarra brasileira.
- `jazz-guitar/index.html`: página dedicada à aula/tema de guitarra jazz.
- `play-like-slash/index.html`: página dedicada à aula/tema “Play Like Slash”.
- `rock-improvisation/index.html`: página dedicada à aula/tema de improvisação no rock.

## Organização adotada

- Cada tema de aula possui uma pasta própria com seu `index.html`.
- Recursos compartilhados (como CSS e imagens) ficam centralizados em pastas comuns.
- Arquivos de SEO (`robots.txt` e `sitemap.xml`) ficam na raiz para acesso direto dos buscadores.

## Benefícios dessa estrutura

- Facilita manutenção e escalabilidade de novas páginas de aula.
- Mantém separação clara entre conteúdo, estilo e ativos visuais.
- Melhora indexação e descoberta do site em mecanismos de busca.
